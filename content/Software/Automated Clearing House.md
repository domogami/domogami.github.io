# Description

An Automated Clearing House (ACH) or more specifically for the US, the ACH Network, is a set of computers that process the US's transactions in batch jobs. Bank transactions, payments, credit/debit transactions, and many more electronic payment related operations are sent to the ACH which can handle both push and pull transactions.

Funny enough, the ACH only operates Mon-Friday during business hours [source](https://www.nacha.org/content/ach-payments-fact-sheet#:~:text=Payments%20are%20settled%20during%20times,on%20weekends%20and%20federal%20holidays.).
